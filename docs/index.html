How it works

三步，比打开转换网站还快

  1. 01拖住文件

    在 Finder 或桌面上拖住一个或多个文件，先别松手。

  2. 02按一下 ⇧ Shift

    屏幕暗下来，轮盘在鼠标处弹出；再按一次翻到「工具」页。

  3. 03朝格子一甩，松手

    方向对就行，不用拖到格子上。结果存在原文件旁边，原文件不动。

Loadout

轮盘里有什么

拖什么文件，就弹出什么轮盘。第 1 页是格式转换，按 Shift 翻到第 2 页是工具。右上角属性条告诉你这一下会得到什么、牺牲什么。

Wanted level

通缉星级

轮盘一打开，右上角就亮起通缉星：星越多，文件里能追踪到你的信息越多。

  • 照片 / 视频里的 GPS 定位★★
  • 手机或相机型号、拍摄时间、机身序列号各 ★
  • PDF 的作者 / 制作软件 / 主题关键词★★ ★ ★
  • Word 的作者 / 修改人 / 公司名★★ ★ ★

指向「去隐私」格子时星星开始闪，表示它会处理这些线索；完成后横幅会写明实际处理的范围。照片、视频、PDF、Word 都支持。它不是完整的匿名化工具，分享前请自行再检查一遍。

Mission

翻车也要有仪式感

成功时先响一声武器上膛（手枪拉套筒、霰弹枪“咔嚓”、手雷拔环……），再弹出 MISSION PASSED；失败就压暗屏幕打出 WASTED，顺便告诉你怎么修。

Two styles

格子图标，两种都有

默认是格式图标：一眼看出格式本身的特点，PNG 带透明格、JPG 是风景照、WebP 是浏览器、TIFF 是打印机。菜单栏 →「格子图标」可以换成武器：PNG 突击步枪、JPG 手枪、PDF 火箭筒、抠图 匕首。

Install

安装

  1. 下载 FormatWheel.dmg，双击打开，把「FormatWheel」拖进「Applications」。
  2. 第一次打开时 macOS 会拦一下（“无法验证开发者”）。这是个人做的免费开源小工具，没有付费给苹果做公证，不是病毒：
    macOS 14

    在「应用程序」里右键点 FormatWheel →「打开」→ 弹窗里再点「打开」。

    macOS 15 及以后

    先双击一次，然后去「系统设置 → 隐私与安全性」，拉到下面点「仍要打开」，输入开机密码。

    还是打不开：打开「终端」，粘贴这一行回车，再双击打开。

    xattr -dr com.apple.quarantine /Applications/FormatWheel.app
  3. 菜单栏会多一个小轮盘图标（Dock 里没有），第一次会自动演示一遍。之后在 Finder 里拖住文件、按 Shift 就行。
可选：装上更多「弹药」

WebP 需要 cwebp；AVIF、WebM、MP3、Opus、视频变速等需要 ffmpeg。没装时这些格子显示「未装备」，其他格子照常能用。装了 Homebrew 的话：

brew install ffmpeg webp
